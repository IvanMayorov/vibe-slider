# Vibe Slider

Лента карточек на нативной прокрутке браузера: мышью тянется с инерцией, за краем пружинит, тянется до краёв окна с затуханием, листается стрелками. Без зависимостей, ~5 КБ.

Демо: https://ivanmayorov.github.io/vibe-slider/

*A horizontal card track on native browser scroll: mouse drag with inertia, a spring at the edges, edge-to-edge fade, arrow buttons. No dependencies.*

## Что умеет

- **Нативная прокрутка.** Пальцем и тачпадом лента листается самим браузером (`scroll-snap`), скрипт её не перехватывает.
- **Перетаскивание мышью.** Отпустили — лента докатывается по инерции и мягко встаёт на ближайшую карточку. Движение после отпускания идёт на пружине с критическим затуханием: без рывка на старте и без перелёта.
- **Пружина у края.** За первой и последней карточкой лента тянется втрое медленнее мыши и мягко возвращается. Если схватить её во время возврата, она продолжит с той же оттяжки, без прыжка.
- **Щелчок во время докрутки** не оставляет ленту между карточками: она доезжает до ближайшей.
- **До краёв окна.** Первая карточка стоит по линии контейнера, а лента продолжается до краёв окна, и карточки за контейнером плавно гаснут.
- **Стрелки** листают на столько карточек, сколько видно, с той же плавной докруткой; у края получают класс `is-disabled`.
- После перетаскивания щелчок не открывает ссылку в карточке.
- Учитывает `prefers-reduced-motion`.

## Подключение

```html
<link rel="stylesheet" href="vibe-slider.css">
<script src="vibe-slider.js"></script>
```

Или через сборщик: `require('vibe-slider')` / `import VibeSlider from 'vibe-slider'` (UMD).

## Разметка

```html
<section style="overflow-x: clip">          <!-- родителю нужен overflow-x: clip (или hidden) -->
  <div class="container">                   <!-- лента берёт ширину контейнера и выходит до краёв окна -->
    <button class="js-prev">←</button>
    <button class="js-next">→</button>
    <div class="js-track">
      <a class="card" href="…">…</a>
      <a class="card" href="…">…</a>
      …
    </div>
  </div>
</section>
```

```js
VibeSlider(document.querySelector('.js-track'), {
  slides: '.card',                          // карточки; по умолчанию — дети ленты
  prev: document.querySelector('.js-prev'),
  next: document.querySelector('.js-next')
});
```

Живой пример — [`example/index.html`](example/index.html).

## Параметры

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `slides` | дети ленты | CSS-селектор карточек внутри ленты |
| `prev`, `next` | — | кнопки-стрелки |
| `spring` | `7` | жёсткость пружины: меньше — плавнее и дольше (при 7 движение успокаивается примерно за 0,8 с) |
| `rubber` | `0.35` | насколько медленнее мыши лента идёт за краем |
| `throw` | `260` | насколько далеко лента катится по инерции: скорость (px/мс) × `throw` |

## Методы

`VibeSlider()` возвращает объект (он же лежит в `track.vibeSlider`):

- `go(1)` / `go(-1)` — пролистать вперёд или назад, как стрелкой;
- `update()` — обновить состояние стрелок;
- `refresh()` — пересчитать поля до краёв окна (если контейнер поменял размер не из-за окна);
- `destroy()` — снять обработчики и стили.

## Стили

`vibe-slider.css` задаёт базовую ленту (flex, `scroll-snap`, скрытая полоса прокрутки, промежуток 16px), маску затухания и курсор. Базовый блок можно заменить своими стилями. Скрипт ставит на ленту CSS-переменные:

- `--vibe-g`, `--vibe-gr` — поля от края окна до контейнера слева и справа;
- `--vibe-pull` — текущая оттяжка за край;
- класс `is-dragging` — пока ленту тянут или она докатывается (привязка к карточкам на это время выключена).
